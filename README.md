# 📇 Эмиль гений — английский по любимым YouTube-видео

**[→ Открыть приложение](https://cryptonerf.github.io/eng-project/)** · работает в браузере и как PWA на телефоне

Хотите смотреть любимые каналы на английском, но не хватает словарного запаса?
Вставьте ссылку на видео — приложение выгрузит субтитры и превратит их в колоду
карточек. Выучите слова — и вернитесь к видео подготовленным: вы уже знаете его
лексику, причём в тех самых фразах, где она звучит.

Приложение честно отвечает на главный вопрос: **сколько слов нужно выучить
именно вам, чтобы понять именно это видео** — и говорит, когда уже можно
смотреть.

## Возможности

### 🃏 Карточки из любого видео

Ссылка на YouTube → готовая колода за полминуты. Каждая карточка — это слово,
перевод, **все его значения по частям речи** и **живые примеры из самого видео**
с таймкодами. Устойчивые выражения не рвутся на части: в колоде будет
`kind of`, а не `kind` — иначе перевод врёт. Повторные добавления того же видео
мгновенны: транскрипты кешируются для всех пользователей.

### 🎯 Готовность к видео

Размер колоды — плохая цель: 500 карточек не отвечают на вопрос «сколько
учить». Слова распределены крайне неравномерно, поэтому горстка частых несёт
основную часть речи — и приложение считает, **сколько слов нужно именно вам**:

> В 19-минутном ролике 3Blue1Brown 559 карточек. Но 74 из них поднимают
> понимание с 74% до 90%. А 214 слов встречаются там ровно один раз и стоят
> вместе 7% речи.

Полоса показывает не покрытие, а **пройденный путь до «можно смотреть»**: она
начинается с нуля, заполняется по мере учёбы (выученное целиком, в работе —
наполовину) и достигает 100% ровно в точке готовности. Рядом всегда стоит
понятная форма — «незнакомо каждое 7-е слово», потому что «86%» звучит куда
оптимистичнее, чем есть на самом деле. Кнопка **«учить ключевые»** запускает
сессию ровно из тех слов, что закрывают разрыв, самое частое первым.

### 📏 Тест словарного запаса

Процент понимания бессмыслен без вашего уровня: тысяча самых частых английских
слов сама по себе покрывает ~72% речи **в любом ролике**. Тест — 21 слово из
девяти частотных групп, нужно **выбрать перевод**, а не оценить себя самому
(самооценка систематически завышает). Есть поправка на угадывание, разбор по
всем группам сразу после теста — и возможность поставить уровень руками, если
вы с оценкой не согласны.

### ▶️ Просмотр с интерактивными субтитрами

Ради этого всё и делается. Видео открывается прямо в приложении, субтитры
собраны в **осмысленные предложения** (а не обрывки по таймингу показа) и точно
синхронизированы с речью. Выученные слова подсвечены зелёным, изучаемые —
жёлтым; по любому слову можно тапнуть и увидеть перевод, под каждой строкой
идёт перевод всего предложения. Строку можно повторить, поставить паузу в конце
фразы, а слово, которое не узнали на слух, — вернуть в повторения одним
нажатием.

### 📚 Главы для длинных видео

Часовую лекцию не начать: до порога понимания в ней ~106 слов, это недели.
Длинные ролики разбиваются на главы — **авторские, если они есть у видео**, —
и у каждой своя готовность и свой короткий список: **11 слов вместо 106**. Это
один вечер, после которого эти пять минут уже можно посмотреть с пониманием и
сразу открыть их кнопкой «смотреть».

### 🧠 Интервальные повторения (SRS)

Алгоритм SM-2, как в Anki: оценили карточку — она вернётся ровно тогда, когда
вы вот-вот её забудете. Слово считается выученным, когда интервал дорастает до
21 дня. Дневная порция собирается из всех видео сразу, каждая карточка приходит
со своим контекстом и его переводом — и её **видно списком до начала
повторения**, на вкладке «к повторению» в словаре. Управление с клавиатуры:
пробел — перевернуть, 1–4 — оценить.

### ▶️ Фразы голосом спикера

Тап по таймкоду — и встроенный плеер проигрывает **ровно ту фразу из видео**,
где встретилось слово: старт с нужной секунды, автостоп в конце фразы, кнопка
«ещё раз». Плюс озвучка любого слова и предложения синтезом (TTS).

### 📈 Прогресс, который видно

- **Готовность** у каждого видео и у каждой главы — и в списке коллекций тоже.
- **Стрик** 🔥 — дни занятий подряд, счётчик выученного, повторения за сегодня.
- **Мой словарь** — все слова со всех видео: *к повторению / изучаю / выучил /
  знаю*, с источниками и сроками повторений.
- **Фильтр по состоянию** в колоде: в работе / выучено / все слова.

### 🧹 Умный словарь

- **Лемматизация**: ran, running и runs — одна карточка «run» (148 неправильных
  форм + проверка окончаний по словарю). Термины проверяются по самому видео:
  `neurons` склеивается с `neuron`, потому что ролик говорит и так, и так.
- **281 устойчивое выражение** ловится целиком, до разбора на слова.
- **Фильтр мусора**: обрывки субтитров, не-слова и стяжения служебных слов
  (`you'd`, `don't`) в колоду не попадают — но в режиме просмотра остаются
  кликабельными.
- **Сложность по частотности**: цвет карточки = уровень слова (зелёный —
  простое, жёлтый — среднее, терракотовый — редкое).
- **«Уже знаю»** — одно нажатие убирает слово из всех видео навсегда.

### ❓ Механика изучения

Отдельная страница в шапке: подробно и без магии — как из субтитров получается
колода, что означает каждое состояние слова, как считается готовность, что
именно двигает полосу и в чём польза такой формы обучения.

### 🔑 Синхронизация без аккаунта

Приложение не спрашивает ни почту, ни имя и не использует вход через сторонние
сервисы. Прогресс привязан к случайному ключу (120 бит), который создаётся в
браузере при первом запуске; на сервер уходит только его хеш — по нему
находятся данные, а восстановить из него ключ нельзя. Второе устройство
подключается коротким кодом: он живёт 10 минут, сгорает после первого
применения, и длинный ключ набирать руками не нужно.

### 📱 Как приложение на телефоне

PWA: «Добавить на экран домой» — и это полноценное приложение со своей иконкой,
офлайн-режимом для повторений и синхронизацией между устройствами.

### 📤 Экспорт

Колода выгружается в Anki (TSV с подсветкой примеров) или в CSV-таблицу.

## Как устроено

```text
Клиент (React + Vite + TS + Tailwind, PWA)  ←  GitHub Pages
   │
   ├── Firebase Auth        только анонимная сессия (заслон от посторонних)
   ├── Cloud Firestore      spaces/{хеш ключа}: колоды, прогресс слов,
   │                        уровень, статистика, офлайн-кеш из коробки
   └── Cloud Functions      ingest: yt-dlp достаёт субтитры и главы,
                            результат кешируется в Firestore для всех
```

- Перевод EN→RU выполняется прямо в браузере (бесплатный эндпоинт Google
  Translate) и кешируется в данных пользователя.
- Прогресс слова — глобальный: выучили «immune» в одном видео — оно зачтено во
  всех остальных.
- Каждое видео скачивается с YouTube **один раз за всю жизнь приложения**
  (глобальный кеш транскриптов), дальше — мгновенно из базы. Главы приезжают в
  том же ответе, что и субтитры, — без единого лишнего запроса.
- Данные для «готовности» хранятся компактно: ранг слова выводится из него
  самого, поэтому на колоду в 500+ карточек уходит пара килобайт.

## Разработка

```bash
npm run setup          # зависимости + бинарник yt-dlp (для legacy-сервера)
npm run dev            # клиент на localhost:5173 (бэкенд — облачный)
npm run build          # production-сборка клиента
npm run deploy:functions   # деплой Cloud Functions + правил Firestore
```

Деплой фронтенда автоматический: пуш в `main` → GitHub Actions → GitHub Pages.

## Структура

```text
eng-project/
├─ client/                  # React-приложение (PWA)
│  └─ src/
│     ├─ lib/               # words (карточки, лемматизация, разбивка на строки),
│     │                     # coverage (готовность), chapters, level (тест),
│     │                     # srs, vocab, phrases, repo, translate, anki
│     └─ components/        # WordCard, StudyView, WatchView, ChapterList,
│                           # ReadinessBar, LevelTest, Dictionary, Guide…
├─ functions/               # Cloud Functions: ingest (yt-dlp + PoToken + кеш)
├─ .github/workflows/       # автодеплой на GitHub Pages
└─ server/                  # legacy: локальный Express (не используется)
```
